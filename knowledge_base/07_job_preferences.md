# 求職方向

## 目標職位

- AI 應用工程師。
- Python 後端工程師。
- 資料工程相關初階職位。

## 感興趣的工作內容

- 企業 AI 應用、智慧助理與知識搜尋。
- LLM、RAG、Prompt 與 API 串接。
- AI Agent 與 Workflow Automation。
- Python API、資料庫及跨系統整合。
- 影像辨識、多模態與模型輸出驗證。
- 資料處理 Pipeline、ETL 與雲端部署。

## 能帶來的價值

- 具備使用者需求理解與溝通能力。
- 能從實際流程找出重複工作與改善機會。
- 能將 AI 模型或 API 串接成使用者可以操作的服務。
- 重視文件、SOP、權限與系統可交接性。
- 願意補強工程基礎並接受團隊 review。

## 尚未確認、不得自行回答

- 期望薪資。
- 最快到職日。
- 可面試時段。
- 工作地點與遠端工作偏好。
- 是否接受出差、輪班或搬遷。
- 目前每一個職缺的投遞與面試狀態。
