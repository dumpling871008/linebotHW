# 求職方向

## 目前優先順序

林君璇目前以 **AI 應用工程師** 為主要求職方向，並將 **Python 後端工程師** 與 **資料工程相關初階職位** 列為延伸方向。

這個排序代表求職重心，不代表只接受單一職稱。若職務內容包含 AI 應用整合、Python API、資料庫、資料處理或雲端部署，也屬於她願意了解與評估的機會。

### 第一優先｜AI 應用工程師

較感興趣的內容包括：

- 企業 AI 應用、智慧助理與知識搜尋服務。
- LLM API、RAG、Prompt 設計及回答約束。
- AI 模型或第三方 API 與既有系統的整合。
- 影像辨識、多模態應用及模型輸出結果驗證。
- AI Agent 與 Workflow Automation 相關應用。

### 延伸方向｜Python 後端工程師

較感興趣的內容包括：

- Python API 開發與第三方服務串接。
- 資料庫操作、身分驗證與權限控制。
- 背景任務、檔案儲存與跨系統整合。
- Docker、Cloud Run 及 GCP 服務部署。
- 可維護的後端分層、錯誤處理與技術文件。

### 延伸方向｜資料工程相關初階職位

較感興趣的內容包括：

- 資料清理、轉換與載入流程。
- ETL、資料品質檢查與錯誤資料記錄。
- SQL、關聯式資料庫及基礎資料倉儲概念。
- 資料處理 Pipeline 與雲端環境整合。

目前資料工程定位為初階與持續學習方向。她能說明資料從來源、轉換到資料庫的流程，並能在 AI 或文件協助下閱讀及修改既有 Python／SQL；不應描述為已能完全獨立設計大型資料平台。

## 希望參與的工作型態

- 將 AI 模型或 API 串接成使用者可以實際操作的服務。
- 參與從需求釐清、功能拆解到測試與部署的應用開發流程。
- 處理 API、資料庫、資料流程及跨系統整合問題。
- 與團隊合作並透過 code review、文件與實務持續補強工程能力。

## 能帶來的價值

- 具備使用者需求理解、溝通與需求轉譯能力。
- 能從實際流程辨識重複工作、例外情況與改善機會。
- 具備將 AI 模型或外部 API 整合成應用服務的專案經驗。
- 重視文件、SOP、權限邊界與系統可交接性。
- 願意誠實面對能力邊界，接受團隊 review 並持續補強工程基礎。

## 能力與興趣的回答邊界

- 可以說明她以 AI 應用工程師為主要方向。
- 可以說明 Python 後端與資料工程相關初階職位也是願意評估的方向。
- 可以介紹已確認的專案、技術與實作經驗。
- 不可因她對某項技術有興趣，就推論她已具備正式工作經驗或能完全獨立完成。
- 不可將 AI 協作下完成的專案描述為完全未使用工具、由本人獨立從零開發。
- 不可替她判斷某一個尚未提供內容的職缺是否一定願意接受。

## Bot 建議回答

### 如果被問「你最想找什麼工作？」

林君璇目前以 AI 應用工程師為主要求職方向，希望參與 LLM、RAG、智慧助理、AI API 串接或多模態相關的應用開發。Python 後端工程師及資料工程相關初階職位也是她願意評估的延伸方向，尤其是包含 API、資料庫、資料處理與雲端部署的工作。

不是。AI 應用工程師是目前的主要方向，但若職務內容與 Python 後端、API 串接、資料庫、ETL 或雲端整合相關，她也願意進一步了解。

### 如果被問「是否能勝任資料工程師？」

她目前將資料工程定位為初階與持續補強的方向，已實作資料產生、PostgreSQL 建表與查詢、Docker Compose 資料庫環境及 Pentaho ETL 轉換流程。她能說明流程並閱讀、修改既有 Python／SQL，但從零設計完整資料平台仍需要 AI、文件或團隊協助。
