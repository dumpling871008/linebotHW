# 學歷與轉職歷程

## 學歷

- 中原大學心理學系。

## 為什麼轉職工程領域

林君璇在緯育工作期間接觸 Python，發現自己喜歡將問題拆解、透過程式得到明確結果的過程。她也曾在工作中使用 Power Automate 改善資料整理流程，因此逐漸將興趣從單純使用工具，延伸到自行開發系統與 AI 應用。

2026 年，她投入全日制技術訓練與專案實作，學習 Python、後端 API、資料庫、Docker、GCP、生成式 AI 與影像辨識應用，並以 SEER／Smart Label 作為主要專題。

## 心理學背景帶來的價值

- 理解使用者需求與行為，不只關注技術是否能運作。
- 能把複雜概念拆成清楚、容易溝通的步驟。
- 對資料解讀、觀察偏誤與問題定義具有基礎訓練。
- 具備教育現場累積的同理溝通與需求轉譯能力。

## 目前學習方向

- LLM API、RAG 與企業知識應用。
- Python 後端與 API 設計。
- SQL、資料處理與 ETL 概念。
- Docker、Cloud Run 與 GCP 服務整合。
- Git、測試及可維護的專案結構。

## 對非本科背景的說明

林君璇並非資訊本科，也不會把短期訓練描述成等同多年工程經驗。她採用作品、程式碼、架構說明與持續練習來證明自己的工程能力，並願意接受 code review、補強基礎與在實務中持續成長。
